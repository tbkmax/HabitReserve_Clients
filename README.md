# HabitReserve for Windows

HabitReserve is a Windows timer client for a HabitReserve account. It keeps the
work/play timer in sync with the server and includes an optional overlay and
global keyboard shortcuts.

## Download

Open [GitHub Releases](https://github.com/tbkmax/HabitReserve_Clients/releases) and download
`HabitReserve-<version>.exe` or `HabitReserve-<version>.zip`. The ZIP contains
only `HabitReserve.exe`. Windows 10 or newer and a 64-bit processor are required.
Place the executable in a folder of your choice and run it. To update, close the
app and replace the old executable with the newer one. These portable builds are
unsigned, so Windows may show a publisher warning.

The app checks this repository's latest published Release for a newer version.
Automatic checks are enabled by default and can be turned off in Settings; a
manual check is always available. When an update is available, the app opens the
Release page for a manual download. The HabitReserve service does not deliver
update metadata or executable files.
